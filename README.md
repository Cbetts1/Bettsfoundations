# Betts Foundations

> AI-powered digital ecommerce platform — optimised for **AlmaLinux 9 VPS** with limited disk space.

**Live URL:** https://bettsfoundations.org  
**Server:** 74.208.52.159

---

## 🏗️ Architecture

```
bettsfoundations.org (NGINX reverse-proxy)
      ├── /          → Next.js frontend (port 3000)
      └── /api/      → Express backend  (port 4000)
                             └── SQLite database (/data/store.db)
                             └── PDF uploads     (/app/uploads/)
```

**Stack:**
| Layer | Tech |
|-------|------|
| Frontend | Next.js 14 (standalone output) + Tailwind CSS |
| Backend | Node.js + Express |
| Database | SQLite via better-sqlite3 |
| Payments | Stripe Checkout |
| AI | OpenAI API (gpt-4o-mini) |
| Reverse Proxy | NGINX |
| SSL | Let's Encrypt (auto-renewal) |
| Containers | Docker + Docker Compose |

## 🚀 One-Command Deploy

```bash
# 1. Clone the repo on your VPS
git clone https://github.com/Cbetts1/Bettsfoundations.git /opt/bettsfoundations
cd /opt/bettsfoundations

# 2. Run the installer (as root)
sudo bash install.sh
# → First run: creates .env template and exits
# → Edit .env with your API keys, then run again

# 3. Fill in .env
nano /opt/bettsfoundations/.env

# 4. Re-run to complete deployment
sudo bash install.sh
```

## ⚙️ Environment Variables

Copy `.env.example` → `.env` and fill in:

| Variable | Description |
|----------|-------------|
| `JWT_SECRET` | Auto-generated by install.sh (64-byte random) |
| `STRIPE_SECRET_KEY` | From [Stripe Dashboard](https://dashboard.stripe.com/apikeys) |
| `STRIPE_WEBHOOK_SECRET` | From Stripe webhook endpoint setup |
| `OPENAI_API_KEY` | From [OpenAI Platform](https://platform.openai.com/api-keys) |
| `ADMIN_EMAIL` | Admin account email |
| `ADMIN_PASSWORD` | Admin account password |

## 🤖 AI Features (OpenAI only — no local models)

| Feature | Endpoint |
|---------|----------|
| Generate product description | `POST /api/ai/generate-description` |
| Suggest pricing | `POST /api/ai/generate-pricing` |
| Generate ebook outline + intro | `POST /api/ai/generate-ebook` |

AI results are cached 24 hours in SQLite to minimise API costs.  
Toggle AI on/off instantly from the Admin dashboard.

## 💳 Stripe Setup

1. Create a **Webhook endpoint** in your [Stripe Dashboard](https://dashboard.stripe.com/webhooks):
   - URL: `https://bettsfoundations.org/api/orders/webhook`
   - Event: `checkout.session.completed`
2. Copy the **Webhook signing secret** → `.env` → `STRIPE_WEBHOOK_SECRET`
3. Test with Stripe card `4242 4242 4242 4242`

- Non-root Docker containers
